# Certificado Profesional de Ciberseguridad de Google
- Comprender la importancia de las prácticas de ciberseguridad y su impacto para las organizaciones.
- Proteja las redes, los dispositivos, las personas y los datos de accesos no autorizados y ciberataques mediante herramientas de gestión de eventos e información de seguridad (SIEM).
- Identifique los riesgos, amenazas y vulnerabilidades más comunes, así como las técnicas para mitigarlos.
- Adquiera experiencia práctica con Python, Linux y SQL.

- Vulnerability Management
- Endpoint Detection and Response
- Hardening
- Network Security
- Security Awareness
- Threat Detection
- Cyber Threat Intelligence
- Threat Management
- Threat Modeling
- Network Protocols
- Intrusion Detection and Prevention
- Computer Security Incident Management
- Cybersecurity
- Incident Response
- Debugging
- Web Presence
- SQL

## Herramientas que aprenderás
- Bash (Scripting Language)
- Python Programming
- Linux
