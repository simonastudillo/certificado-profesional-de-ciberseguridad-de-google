# Más información sobre marcos y controles

## Bienvenido al módulo 2
- Como analista de Seguridad, ​su trabajo no consiste solo en proteger a las organizaciones
- ​También estás ayudando a mantener a las personas seguras.
- Las infracciones que afectan a los ​datos de los clientes, proveedores y empleados pueden causar un daño significativo a la ​estabilidad financiera y la reputación de las personas.
- ​analizaremos los marcos de Seguridad, los controles ​y los principios de diseño con más detalle, y cómo ​se pueden aplicar a las auditorías de seguridad para ayudar a ​proteger a las organizaciones y a las personas. 
- El marco de ciberseguridad del NIST ​desempeña un papel importante en esto
- El framework garantiza la protección y el cumplimiento de las ​herramientas de los clientes y los dispositivos de trabajo personales ​mediante el uso de controles de Seguridad

## Marcos
- ​En una organización, se establecen planes para proteger ​contra una variedad de amenazas, Riesgos y vulnerabilidades
- ​Sin embargo, los Requisitos utilizados para proteger ​a las organizaciones y a las personas a menudo se solapan
- Por ello, las organizaciones utilizan los marcos de seguridad como ​punto de partida para crear ​sus propias políticas y procesos de seguridad
- Los frameworks de seguridad son directrices utilizadas para construir ​planes que ayuden a mitigar los riesgos y ​amenazas a los datos y la privacidad, ​como los ataques de ingeniería social y el ransomware
- ​La seguridad implica algo más que el espacio virtual. ​También incluye el físico, ​por lo que muchas organizaciones tienen ​planes para mantener la seguridad en el entorno de trabajo. 
- ​Por ejemplo, el acceso a un edificio ​puede requerir el uso de una tarjeta llave o una tarjeta de identificación
- Otros marcos de seguridad proporcionan ​orientaciones sobre cómo prevenir, ​detectar y responder a las brechas de seguridad
- Esto es especialmente importante ​cuando se trata de proteger a una organización de ​ataques de ingeniería social como el ​phishing dirigidos a sus empleados
- Recuerde que las personas son la mayor amenaza para la Seguridad.
- ​Por ello, pueden utilizarse marcos para crear planes que aumenten ​la concienciación de los empleados y les eduquen sobre ​cómo pueden proteger a la organización, ​a sus compañeros de trabajo y a sí mismos
- Educar a los empleados sobre los retos de seguridad existentes es ​esencial para minimizar la posibilidad de una brecha. 
- Proporcionar entrenamiento a los empleados sobre cómo ​reconocer las banderas rojas, o amenazas potenciales, es ​esencial, junto con tener planes en marcha ​para informar y abordar rápidamente los problemas de seguridad. 
- Como analista, será ​importante que comprenda y ​implemente los planes que su organización ​tiene en marcha para mantener a la organización, ​sus empleados y las personas a las que ​sirve a salvo de ataques de ingeniería social, ​brechas y otros incidentes de seguridad perjudiciales.

## Controles
- ​Mientras que los frameworks se utilizan para crear ​planes para hacer frente a los riesgos de Seguridad, ​amenazas y vulnerabilidades, ​los controles se utilizan para reducir riesgos específicos
- Si no se aplican los controles adecuados, ​una organización podría enfrentarse a importantes impactos financieros ​y a daños en su Reputación ​debido a la exposición a riesgos ​incluyendo el allanamiento de morada, la creación de cuentas falsas de empleados, ​o la concesión de beneficios gratuitos
- Los controles de seguridad son salvaguardas ​diseñadas para reducir riesgos de seguridad específicos
   - Encriptación
      - La encriptación es el proceso de convertir datos ​de un formato legible a un formato codificado.
      - ​Típicamente, la encriptación implica convertir ​datos de texto plano a texto cifrado. 
      - ​El texto cifrado es el mensaje en bruto, codificado ​que es ilegible para humanos y ordenadores
      - Los datos de texto cifrado no pueden leerse hasta que ​se hayan desencriptado a su forma original de texto plano
      - ​La encriptación se utiliza para garantizar ​la confidencialidad de los datos sensibles, ​como la información de las cuentas de los clientes ​o los números de la seguridad social
   - Autenticación
      - La autenticación es el proceso de ​verificar quién es alguien o algo
      - Un ejemplo real de autenticación es ​registrarse en un sitio web con su nombre de usuario y contraseña
      - Esta forma básica de autenticación demuestra que ​usted conoce el nombre de usuario y la contraseña ​y que se le debe permitir el acceso al sitio web. 
      - Métodos de autenticación más avanzados, ​como la autenticación multifactor, o MFA, ​desafían al usuario a ​demostrar que es quien dice ser ​exigiendo tanto una contraseña ​como una forma adicional de autenticación, ​como un código de seguridad o datos biométricos, ​como una huella dactilar, ​una voz o un escáner facial
      - Los datos biométricos son características físicas únicas ​que pueden utilizarse para verificar la identidad de una persona
      - Ejemplos de datos biométricos son una huella dactilar, ​un escáner ocular o un escáner de la palma de la mano
      - Un ejemplo de ataque de ingeniería social ​que puede explotar los datos biométricos es el vishing
      - El vishing es la explotación de ​comunicaciones electrónicas de voz para ​obtener información sensible o ​suplantar la identidad de una fuente conocida
      - Por ejemplo, el vishing podría utilizarse para suplantar ​la voz de una persona para robar ​su identidad y luego cometer un delito
   - Autorización
      - La autorización se refiere al concepto de ​otorgar acceso a recursos específicos dentro de un sistema
      - ​Esencialmente, la autorización se utiliza para verificar ​que una persona tiene permiso para acceder a un recurso
      - Por ejemplo, si trabaja como ​analista de seguridad de nivel básico ​para el gobierno federal, ​podría tener permiso para acceder a ​datos a través de la deep web o ​otros datos internos a los que sólo ​puede acceder si es empleado federal
- Controles de seguridad de los que hemos hablado ​hoy son sólo un elemento de ​un modelo de seguridad básico conocido como la tríada CID
