- El siguiente bloque de código define y llama a una función. ¿Qué componente del código es un argumento?
```python
def display_username(username):
   print("Username is", username)
display_username("bmoreno")
```
   - [ ] display_username()
   - [ ] username
   - [ ] print()
   - [x] "bmoreno"
> En este bloque de código, el componente que es un argumento es "bmoreno". Los Argumentos son los Datos que se introducen en una función cuando ésta es llamada.

   - [ ] Las bibliotecas de Python contienen funciones, pero los módulos de Python no.
   - [ ] Las bibliotecas de Python contienen variables, pero los módulos de Python no.
