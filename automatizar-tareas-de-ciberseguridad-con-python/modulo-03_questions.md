- ¿Qué cadena coincide con la expresión regular "b\wa+b"?
   - [ ] "cba"
   - [x] "bkaaab"
   - [ ] "yaaab"
   - [ ] "baaa"
> La Cadena "bkaab" coincide con la expresión regular "b\wa+b". El primer carácter debe ser "b". Después, el símbolo \w se utiliza para coincidir con cualquier carácter alfanumérico, incluido "k". A continuación, el símbolo + especifica que debe haber una o más apariciones del carácter al que sigue, que en este caso es "a". Por último, la cadena debe terminar con "b".
