- ¿Qué salida tiene el código print("HELLO"[2:4])?
   - [ ] "LLO"
   - [ ] "EL"
   - [ ] "E"
   - [x] "LL"
> El Código print("HELLO"[2:4]) da como salida "LL". El primer índice de la rebanada se incluye en la salida, pero el segundo índice de la rebanada no se incluye. Esto significa que la rebanada comienza en el carácter del índice 2 y termina un carácter antes del índice 4.
