- ¿Qué le indica a Python la línea de código with open("ip_addresses.txt", "r") as file:? Seleccione dos respuestas
   - [ ] Escriba la cadena "r" en el archivo "ip_addresses.txt" 
   - [ ] Cree un nuevo archivo llamado "ip_addresses.txt"
   - [x] Almacene el objeto de archivo en la variable file dentro de la sentencia with 
   - [x] Abra el archivo "ip_addresses.txt" para poder leerlo
> La línea de código with open("ip_addresses.txt", "r") as file: indica a Python que abra el archivo "ip_addresses.txt" para leerlo ("r"). También instruye a Python para que almacene el objeto del archivo en la variable file mientras está dentro de la sentencia with.
