# Distribuciones Linux

## Distribuciones Linux
- ​Linux es un sistema operativo muy personalizable. ​A diferencia de otros sistemas operativos, hay diferentes versiones disponibles ​para su uso.
- ​Estas diferentes versiones de Linux se denominan distribuciones.
- ​Es posible que también escuche que se llaman distribuciones o sabores de Linux.
- ​Es fundamental que comprenda la distribución que está utilizando ​para saber qué herramientas y aplicaciones están disponibles para usted.
- ​Por ejemplo, ​Debian es una distribución que tiene herramientas diferentes a las de la distribución de Ubuntu.
- ​Usemos una analogía para describir las distribuciones de Linux.
- ​Piense en el OS como un vehículo.
- ​En primer lugar, empezaremos con su motor, que sería el kernel.
- Del mismo modo que el motor ​hace funcionar un vehículo, el kernel es el componente más importante del sistema operativo Linux.
- ​Como el kernel de Linux es de código abierto, cualquiera puede tomar el kernel y ​modificarlo para crear una nueva distribución.
- ​Esto es comparable a que un fabricante de vehículos tome un motor y ​cree diferentes tipos de vehículos: camiones ​, automóviles, furgonetas, convertibles, autobuses, aviones, etc. 
- Estos diferentes tipos de vehículos se pueden comparar con diferentes distribuciones de Linux.
- Las diferentes distribuciones de Linux contienen diferentes programas preinstalados ​, interfaces de usuario y mucho más.
- ​Gran parte de esto se basa en las necesidades del usuario de Linux, pero ​algunas distribuciones también se eligen según sus preferencias, de la ​misma manera que se puede elegir un automóvil deportivo como vehículo.
- ​La ventaja de usar Linux como sistema operativo es que puedes personalizarlo.
- Las ​distribuciones incluyen el kernel de Linux, las utilidades, ​un sistema de administración de paquetes y un instalador.
- Hemos aprendido anteriormente que Linux es de código abierto y ​que cualquiera puede contribuir a añadir código fuente.
- ​Así es como se crean las nuevas distribuciones.
- ​Todas las distribuciones se derivan de otra distribución, pero ​hay algunas que se consideran distribuciones principales.
- ​Red Hat® es la empresa matriz de CentOS y Slackware® es la empresa matriz de SUSE®.
- ​Tanto Ubuntu como KALI LINUX™ se derivan de Debian.

## KALI LINUX
- ​KALI LINUX™ es una marca comercial de Offensive Security y es un derivado de Debian.
- ​Esta distribución de código abierto se hizo específicamente teniendo en cuenta las pruebas de penetración y ​la forense digital.
- ​Hay muchas herramientas preinstaladas en KALI LINUX™.
- ​Es importante tener en cuenta que KALI LINUX™ debe utilizarse en una máquina virtual.
- ​Esto evita daños en su sistema en caso de que sus herramientas se utilicen de forma incorrecta.
- ​Una ventaja adicional es que el uso de una máquina virtual le ofrece la posibilidad de ​revertir a un estado anterior.
- Una prueba de penetración es un ataque simulado que ayuda a identificar vulnerabilidades en ​sistemas, redes, sitios web, aplicaciones y procesos.
- ​KALI LINUX™ dispone de numerosas herramientas que resultan útiles durante las pruebas de penetración. 
- Veamos algunos ejemplos.
- ​Para empezar, Metasploit puede utilizarse para buscar y explotar vulnerabilidades en máquinas.
- ​Burp Suite es otra herramienta que ayuda a probar puntos débiles en aplicaciones web.
- ​Y, por último, John the Ripper es una herramienta que se utiliza para adivinar contraseñas.
- ​Como analista de seguridad, su trabajo podría implicar la investigación forense digital.
- ​El análisis forense digital es el proceso de recopilación y ​análisis de datos para determinar qué ha ocurrido tras un ataque.
- ​Por ejemplo, ​puede que eche un vistazo de investigación a los datos relacionados con la actividad de la red.
- KALI LINUX™ también es una distribución útil para ​profesionales de la seguridad que se dedican al análisis forense digital.
- ​Tiene un gran número de herramientas que pueden utilizarse para ello.
- Como ejemplo, ​tcpdump es un analizador de paquetes de línea de comandos.
- Se utiliza para capturar tráfico de red.
- ​Otra herramienta muy utilizada en la profesión de la seguridad es Wireshark.
- ​Tiene una interfaz gráfica de usuario que puede utilizarse para analizar en directo y ​capturar tráfico de red.
- ​Y como último ejemplo, ​Autopsy es una herramienta forense utilizada para analizar discos duros y smartphones.
- ​Esta distribución cuenta con muchas herramientas utilizadas para llevar a cabo pruebas de penetración y análisis forenses digitales.
