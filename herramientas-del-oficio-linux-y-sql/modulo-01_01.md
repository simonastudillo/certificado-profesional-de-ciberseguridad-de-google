# Comenzar el curso

## Introducción al curso 4
- ​Bienvenido a este curso ​sobre fundamentos informáticos para la seguridad.
- ​El enfoque de este curso son los fundamentos de la informática.
- ​Cuando entienda cómo ​funcionan las máquinas en el sistema de una organización, ​le ayudará a hacer su trabajo como ​analista de seguridad de forma más eficiente.
- ​Parte de su trabajo como analista de seguridad es ​mantener los sistemas protegidos de posibles ataques.
- ​Usted es uno de los primeros niveles de ​defensa en la protección de los datos de una organización.
- ​Para hacerlo con eficacia, ​es útil comprender cómo ​funciona el sistema que está protegiendo.
- ​Además, puede que necesite ​investigar eventos para ayudar a corregir errores en el sistema.
- ​Estar familiarizado con el sistema operativo Linux ​y sus comandos asociados, ​y también ser capaz de interactuar con ​los datos de una organización a través de ​SQL, le ayudará con eso.
- ​En este curso, aprenderá sobre ​los sistemas operativos y cómo se ​relacionan con las aplicaciones y el hardware.
- ​A continuación, explorará ​el sistema operativo Linux con más detalle.
- ​Después, utilizará la línea de comandos de Linux ​dentro de un contexto de seguridad.
- ​Por último, hablaremos de cómo puede utilizar SQL para consultar ​bases de datos mientras trabaja como analista de seguridad.
